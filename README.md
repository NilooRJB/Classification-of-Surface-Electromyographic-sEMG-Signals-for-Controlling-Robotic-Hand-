# Classification-of-Surface-Electromyographic-sEMG-Signals-for-Controlling-Robotic-Hand-
Surface electromyography (sEMG) is a non-invasive method of measuring neuromuscular potentials generated when the brain instructed the body to move. This method also can be used in controlling artificial hand. This paper presented a method to classifier 8 hand gestures (idle, fist, flexion, extension and 4 pinches) that acquired from 44 subjects. The method consisted of LDA, QDA, KNN and SVM classifier which exerted on RMS, Du’s, Hudgins feature sets. The total accuracy of 80% was achieved in this work.
